# 格式示例

`.txt` 与 `.md` 使用同一套规则，后缀只影响文件关联，不影响解析。

## 最小结构

```text
# 书名

## 第一章

正文。
```

- 第一行非空内容必须是 `# ` + 书名。
- 至少一个 `## ` + 章节名。
- 标记后面必须有一个半角空格。
- 书名与第一个 `##` 之间的文字不是错误：它会成为不参与编号的「引言」章节（也可以是序、写在前面之类的内容）。

## 完整示例

```markdown
# 三体

写在前面：这是一段引言，会显示为“引言”，不占用章节编号。

## 第一章 科学边界

汪淼觉得，来找他的这四个人是一个奇怪的组合：两名警察和两名军人。

“我们想请你帮个忙。”史强说。

## 第二章 射手与农场主

“射手假说”和“农场主假说”……

## 第三章 宇宙闪烁

凌晨一点，汪淼被电话吵醒。
```

## 会被拒绝的写法

| 写法 | 原因 |
| --- | --- |
| `#三体`（没有空格） | 标题标记后需要一个半角空格 |
| 两个 `# ` 书名 | 一本书只能有一个书名 |
| `### 小节` | 暂不支持三级及以上标题 |
| 只有 `##` 没有章节名 | 章节名不能为空 |
| `## 章节名` 之后没有正文 | 每一章都需要正文 |

错误信息会指出具体行号，例如「第 12 行：书名为空」。导入失败不会替换当前小说，也不会清除阅读进度。

## 编码

优先按 UTF-8 读取。`.txt` 解码失败时会询问是否按 GB18030 重试；`.md` 只接受 UTF-8。CRLF 换行与 UTF-8 BOM 会自动处理。
