# 摸鱼阅读

在 DeepSeek Harness 的侧栏面板列表里点一下书本图标（和 Plugins 并排），主区域会显示当前小说与导入按钮；再点一下就把独立小窗浮到桌面上，用来离线性阅读一本小说。

## 为什么是独立窗口

阅读窗口不是 DSH 页面里的浮层，也不是浏览器弹窗。它是插件自己启动的 Electron 进程，复用 DSH 安装包内已经存在的 Electron 运行时，平时不额外占用空间，也不需要另装一套浏览器。

- DSH 主窗口最小化、隐藏，甚至关闭但进程还在时，阅读窗口继续存在。
- DSH 真正退出、窗口崩溃或握手超时时，辅助进程会被清理，不留下孤儿进程。
- 任意时刻最多只有一个阅读窗口；重复点入口只会恢复并聚焦已有窗口。

## 数据放在哪里

小说正文、进度、偏好与快捷键都保存在插件私有目录，不写入 Session 或 Workspace，也不记录原文件路径。导入时正文会被复制，之后删除原文件不影响阅读。

设置页里的「清除阅读数据」需要点击两次确认。

## 快捷键

三项快捷键使用操作系统级注册，其他应用聚焦时同样可用：

- 隐藏 / 恢复窗口：默认 `Ctrl + ;`
- 上一页：默认 `Ctrl + ,`
- 下一页：默认 `Ctrl + .`

macOS 上的 `Ctrl` 指 Control（⌃）。全部可以重新录制或单独恢复默认。

## 语言

界面跟随 DSH 当前语言，中文与 English 即时切换，独立窗口也会同步；DSH 不可用或语言不受支持时回退到 English。书名、章节名与正文从不翻译，只自动生成「第一章 / Chapter 1」这样的章节序号。

## 格式

`.txt` 与 `.md` 规则完全一致：第一条非空内容是 `# 书名`，之后每个 `## 章节名` 开始一章。三级标题、缺失书名、空章节都会在导入时被拒绝，并指出行号；书名与第一章之间的文字会保留为不编号的「引言」，不再是错误。窗口内可以随时打开格式示例。
